# hacktv-gui - a GUI frontend application for hacktv

hacktv-gui is, as the name suggests, a GUI frontend application for hacktv, which is available at https://codeberg.org/fsphil/hacktv/ or https://github.com/captainjack64/hacktv/. It allows you to run hacktv without the use of a command line. In addition, it includes playlist support, a handler for online teletext services, and support for any streaming video site which is compatible with yt-dlp. You can also save your settings to a file and reload them later.

**Downloads are available in the <a href="https://github.com/steeviebops/hacktv-gui/releases/latest/">Releases</a> section.**<br>
**For Linux or Mac, details on how to install and use can be found on the <a href="https://github.com/steeviebops/hacktv-gui/wiki/Getting-started">Getting Started</a> wiki page.**

### Prerequisites
- A Java 21 or later runtime environment is required. Java 8 will not work. <a href="https://adoptium.net">Temurin</a> or <a href="https://www.microsoft.com/openjdk">Microsoft's build of OpenJDK</a> have been tested.
- To use yt-dlp features, a copy of <a href="https://github.com/yt-dlp/yt-dlp/releases/">yt-dlp</a> is required. This can be either in your system path, or placed in the same directory as the JAR file. The Windows installer provides a yt-dlp download as an optional extra.
